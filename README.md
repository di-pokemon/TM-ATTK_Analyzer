# Threat Modeling & Attack Path Analyzer

## Overview
A STRIDE-based threat modeling tool that analyzes system architecture and generates attack paths, threat categories, and risk scores.

## Features
- STRIDE threat generation
- Attack path simulation
- Risk scoring engine
- Security report generation

## Why this matters
Used in Application Security (AppSec) and Secure SDLC processes to identify system-level risks before development.
